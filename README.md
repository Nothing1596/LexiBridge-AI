# LexiBridge-AI
LexiBridge AI 是面向中外合作办学课程的 AI 双语课程知识对齐平台，通过资料解析、术语抽取、证据检索、教师质控和学生反馈，构建可追溯、可验证、可迭代的双语专业概念网络。
# Description

LexiBridge AI is an AI-assisted bilingual course knowledge alignment platform for Sino-foreign cooperative education.

It is not a direct word-by-word translation tool. Its goal is to build a traceable, reviewable, and iteratively improvable bilingual professional concept network from course materials, evidence chunks, teacher review, and student feedback.

Current implementation is a local MVP based on Flask, SQLite, document parsing, deterministic retrieval, and an optional local DocLayout-YOLO ONNX layout provider.
