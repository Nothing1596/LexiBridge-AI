当前系统定位

当前版本不是完整 AI 翻译系统，而是教师审核型术语标准化平台原型。 它不会伪造中文专业译名；系统只做候选术语抽取，最终中文译名和专业解释由教师审核确认。 后续可在后端预留接口中接入 AI API 和 RAG 知识库。
